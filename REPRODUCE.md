# Transcript switches and the timing of development

Version [v1.0.0](https://github.com/Kohze/developmental-transcript-switches/tree/v1.0.0). Open Developmental_transcript_switches.pdf or Developmental_transcript_switches.html to read the review.

Install Python, the packages in requirements.txt and Tectonic. Set TECTONIC to its executable path if necessary. From this directory run:

```sh
python -m pip install -r requirements.txt
python build_review.py
python qa/validate.py
python qa/check_figures.py
```

Source studies, workbooks and figure credits are listed in research/figure_provenance.csv and qa/display_item_credits.csv.
